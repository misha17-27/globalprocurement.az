# globalprocurement.az

Redesign of globalprocurement.az (Global Procurement Group MMC) — migration from WordPress to PHP.

## Homepage design variants (static HTML)

| File | Style |
|---|---|
| `index-v1.html` | Corporate — navy hero, light sections |
| `index-v2.html` | Light editorial — serif headings, bento grid |
| `index-v3.html` | Dark industrial — catalog filter, OSB calculator |
| `index-v4-dark.html` | Rich dark — hero slider, mega menu, house material guide, quick-view catalog |
| `index-v5-light.html` | Rich light — header search, sidebar catalog, OSB comparison table, articles |

Images are in `assets/img/` (downloaded from the current site).
